# 茶茶日历 1.5.0

面向安卓 8.0（接口级别 26）及以上设备的离线优先日历。首版重点解决“纪念日只有临近时才出现”的问题。

应用包名：`com.liangledecha.chachacalendar`

## 已实现

- 自动适配状态栏、刘海/打孔区域和底部导航栏安全区。
- 上下拖动月历区域，在单周、常规整月、全屏标签月历三种状态间流畅切换。
- 月视图左右滑动切换上/下个月；年视图左右滑动切换上/下一年，并带位移、淡入淡出动画。
- “年”提供 iPhone 风格的 12 个月缩略总览，点击任意月份进入对应月；“日程”列出全部事项。
- 点击年月标题打开年份、月份双滚轮，可直接跳转。
- 底部固定提供“日历 / 待办 / ＋”导航；待办页只展示待办类型事项。
- 底部提供“今 / 日历 / 日程 / 待办 / ＋”，顶部只保留年、月视图。
- 支持纪念日、生日、待办和倒数日；重复规则包括每年、每月、每周、每日和不重复。
- 选中任意日期后，下半区以该日期为基准严格执行提前显示窗口；例如“15天前显示”只展示之后 0–15 天内的事项。
- 全屏月历在日期格内显示纪念日、生日和待办标签。
- 每条日程可独立选择：一直显示（默认）、15、7、5、3 天前显示。
- 下半区按下一次发生日期排序，持续显示倒计时；点击编辑，长按删除。
- 每年重复或一次性日程。
- 最左侧 ISO 年周数显示，可在设置中关闭。
- 桌面小组件包含系统驱动的实时钟、日期和最近纪念日。
- 自动探测主流厂商系统天气应用，天气区域可直达系统天气。

## 架构与功耗

- `EventStore`：SQLite 单一数据源，不需要联网。
- `MonthCalendarView`：原生 Canvas 绘制三态月历，避免复杂 UI 框架常驻开销。
- `MainActivity`：编辑、筛选和视图状态协调。
- `CalendarWidgetProvider`：只在日期、时区或本地数据变化时刷新；时间由系统 `TextClock` 更新，不运行分钟级定时任务。
- `SystemWeatherBridge`：厂商无关的适配边界。目前只调用公开的应用启动入口，不读取私有数据库。

Android 没有统一的公开 API 允许第三方应用读取“系统天气”的温度和预报，各厂商也通常不开放私有天气数据库。为保持跨品牌兼容和零高危权限，首版不会使用 root、无障碍或通知监听。后续可在 `SystemWeatherBridge` 内增加获得厂商正式授权的数据适配器，而不影响日历核心。

## 本地构建

需要 JDK 17 和 Android SDK 35：

```text
gradle assembleDebug
```

源代码不含任何第三方运行时依赖，也不申请网络、定位、日历、通知等权限。
